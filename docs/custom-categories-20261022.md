# EvoMyn 自定义记忆分类验收 · 2026-10-22

本次版本为 Windows 0.2.6。记忆页新增「管理分类」，默认分类为人脉、日志、个人、事件、资料。原 `background` 分类编号保留，默认显示名从「背景」调整为「个人」。

## 行为与数据兼容

- 支持新增分类、改名、上移和下移。默认分类可改名和排序；空的自定义分类可删除，有记忆的分类禁止删除。
- 名称为 1～24 个字符，采用 Unicode NFKC 规范化并忽略大小写检查重复；最多 32 个分类。
- 分类保存在档案 SQLite 数据库的 `personal_archive_categories` 表，随现有数据库备份。改名和排序不改写记忆正文、分类编号及历史版本。
- 老数据库首次使用时建立默认分类表；看板读取旧数据库时也能显示默认分类，不要求立即迁移。
- MCP `archive_status` 返回当前分类编号和名称；`archive_record`、`archive_list` 使用实时分类。工具数仍为 9，既有客户端配置兼容。
- 看板记录正文保持只读；分类设置接口采用同源、CSRF、请求形状及长度校验，不加载记忆 SDK 或模型。分类操作与 MCP 写入共用档案锁。
- MCP 总开关关闭后，仍可管理分类。历史 Docker 只读挂载不提供分类编辑。
