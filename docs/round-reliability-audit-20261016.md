# 圆盘固件检查记录（2026-10-16）

> 历史证据：本文记录当时的部署与验收，不是当前安装要求；地址、设备身份和个人路径已替换为示例。当前入口见项目 README 与 docs/architecture.md。

检查范围：round-voice-175c 定制固件的时钟、联网、页面刷新、设置保存、语音入口、按键与初始化生命周期。没有修改云端服务或电脑原记忆库。

## 已修复

1. **时间重复偏移**：OTA 把时区加进 Unix 时间，屏幕又按东八区转换。改为系统始终保存 UTC，时区只参与显示转换；无效服务器时间不写入。缺少时区时保留板型默认东八区。离线冷启动仍显示待同步，不伪造时间。
2. **断网后不再恢复**：取消只重试三次的限制，保存过的网络按 2、5、10、30 秒退避持续恢复。扫描/连接期间不并发重连，新目标和成功连接取消旧计划。认证明确拒绝时要求用户处理；认证响应超时可重试。已成功过的凭据遇到握手超时也继续恢复。
3. **初始化与切网竞争**：独立的原子标记覆盖激活工作任务的实际生命周期；切换网络和执行协议释放时都检查，避免页面状态提前变为 Idle 后销毁仍在启动的连接对象。忙时保留已输入的密码。
4. **相同内容反复绘制**：时间、日期、联网状态与智能体状态不变时不再重新分配文本/刷新。验证码渲染不再先写占位符再写真实码。实测原生 LVGL 中相同验证码更新 10 次，屏幕传输由 20 次降至 0 次。

保留已验证的 RX8/32、UDP32 音频接收配置、中文字体、2×2 对齐刷新、上移布局和电源键行为。

## 安全检查与保留限制

- 定制配网只开启 STA 模式，没有设备热点或配网 HTTP 服务。密码编辑退出会清空，新的诊断不记录密码。
- HTTPS/TLS 使用证书信任包，没有开启“不校验证书”模式。但当前 SDK 配置未开启证书日期检查，后续需先提供独立可信校时，再启用有效期检查，避免冷启动先取时间时无法联网。
- Wi-Fi 密码保存在未加密 NVS 中；物理读取 Flash 可提取。没有擅自烧写不可逆的加密/安全启动熔丝。
- 上游 MQTT/UDP 音频使用 AES-CTR，包中没有独立消息认证标签；这不是认证加密。增强完整性保护需小智服务端同时支持，不能单改设备协议。
- 未对云端或第三方服务进行渗透测试；不能据此声称设备完全没有漏洞。

## 仍需实机覆盖

路由器重启、长时间离线后恢复、密码变化、弱信号冷启动、长按开关机与连续语音/触控负载。原生测试和构建不能替代这些物理验证。冷启动时的四次握手超时仍可能要求重新确认密码；已保存的凭据不会因此删除。
