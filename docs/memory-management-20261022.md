# 桌面记忆管理与仓库迁移

当前维护仓库为 [ArkFishingLab/EvoMyn](https://github.com/ArkFishingLab/EvoMyn)。新版本使用该仓库的 GitHub Releases 更新源；已保存的旧官方源自动迁移，其他自定义 HTTPS 源保留。旧版应用仍使用旧内置地址，可在设置中填写新源后升级。

## 行为

- 桌面记忆页可新增、编辑和删除；MCP 总开关关闭时仍可使用。默认分类可以改名和排序；空自定义分类可以删除。
- 编辑保留隐藏字段、步骤、关联和附件登记；revision 冲突不覆盖其他客户端的修改，界面保留草稿，重新读取需要明确确认。
- 原文与历史先提交，语义索引异步执行；索引结果必须匹配当前版本。退出时未完成的任务保持待索引，可通过 MCP 重试。
- 删除清理原文、该记录历史和其他活动记录中的关联；事务异常整体回滚。保留最小删除标记及设备事件摘要，阻止重试恢复已删内容。磁盘附件、旧备份与语义引擎物理数据不属于安全擦除承诺。
- 独立 viewer 正文仍只读；桌面与本地 dashboard 显式提供写入 store。写入接口检查同源、CSRF、长度及字段白名单，不向页面返回文件路径或内部索引异常。
