# Windows 0.2.1 接入体验验收 · 2026-10-22

MCP 是独立的本机服务，可以接入 Codex、Claude 等客户端。小智保持为可选连接：普通启动及 MCP 开关不会要求小智账号、打开小智引导或自动开启已暂停的云连接。

显式开启“小智连接”时，先检查已保存的接入点；缺少时打开引导，保留当前本地 MCP 状态。引导提供控制台入口、智能体与角色选择、获取完整 `wss://` 地址的说明。保存后自动启动所需的 MCP 服务及云连接；连接慢或未成功时显示重试与更换接入点提示。已有凭证不回显，暂停云连接不会停止本地 MCP。

顶栏区分本地可用与小智已连接，能力页使用实时云连接状态。云端 MCP 管道接入已有的有界观测器，只记工具名称、调用编号、状态和耗时；不记录参数、响应正文或接入点。桌面内嵌能力页统一使用原生主开关，避免重复启停路径绕过连接引导。修复了服务操作成功返回仍带 `busy:true` 的短暂开关锁定。

## 验证

- Node 32 项通过：独立 MCP、仅云连接触发引导、暂停保留、无效/失败保存、历史云开关状态、IPC 权限和既有更新/退出检查。
- Python 后端 18 项通过：真实 MCP、TLS 桥接、70 KiB 回复、能力页已连接/工具数/调用记录、暂停状态与正文不进入日志。
- HTTP 接入配置 11 项、能力管理 14 项、运行时 staging 4 项通过。
- 隔离 Electron 引导验收：无小智时使用标准 MCP 完成 9 个工具发现及测试档案写入；普通主开关独立；云开关缺配置进入引导；错误输入不影响 MCP；保存本地 TLS 接入点后完成 initialize、工具列表和 archive_status 调用；凭证不回显；能力页状态一致；已保存地址复用；暂停云连接及退出清理。

构建为 Windows x64 0.2.1，使用原公开更新公钥签名离线更新说明。公共 HTTPS 更新源仍未发布。既有个人数据库、云接入点及生产进程未更改；本轮未操作圆盘固件。

控制台入口来自 [小智官网](https://xiaozhi.me/)；接入说明参考上游 [MCP 示例](https://github.com/78/mcp-calculator) 及实现者的 [接入操作说明](https://github.com/LRchangyu/esp_to_xiaozhi_mcp)。菜单可能随控制台版本调整，应用中保留了这一提示。
