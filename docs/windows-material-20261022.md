# Windows 0.2.3 视觉优化验收 · 2026-10-22

依据用户指定的 Codex 视觉方向，重做 Windows 应用的表面层次和控件节奏。只读参考本机应用中的基础色阶和尺寸信息；本项目的样式、SVG 图标和页面布局独立编写，不包含 Codex 程序、图标或字体文件。

- 固定左侧主导航；设置与 MCP 总开关位于侧栏底部。右侧内容使用内嵌白色表面、柔和圆角和细边框。
- 共享视觉变量统一文字、背景、分隔线和控件颜色。缩小标题，使用 12–14 px 正文与控件、轻量悬停及键盘焦点。
- 客户端改为紧凑图文列表，设置改为分组条目；小智仍是可选折叠连接。
- 内嵌记忆分类改为横向上下文筛选，保留搜索、记录详情与备份；能力使用分段页签及统一功能包控件、商城卡片。
- 原生内容与看板位置由小型布局模块计算，普通/最小窗口均检查边界。页面切换滚动内容区，不滚动导航；缺少小智接入点时继续自动展开、滚动并聚焦输入框。

## 验证

Node 34 项通过。隔离开发版验证四个页面、导航竞争、真实 SDK 的 9 个工具、档案写入/展示、TLS 小智接入、凭证不回显、保存重连、独立暂停与退出清理。对两种窗口大小检查横向溢出、原生/看板对齐、七个分类按钮可见、能力页签尺寸；打开记录详情、切换备份和商城，确认新样式不隐藏功能。

看板作者样式的级联覆盖曾导致紧凑窗口分类不可见；已先用实际元素可见性断言复现，再以更明确的桌面样式作用域修复。保留独立网页原有样式和安全策略。看板没有 preload 或原生 IPC。

Windows x64 0.2.3 安装包已构建；打包后的应用通过同一套隔离验收，包括真实搜索无结果/恢复、记录详情、备份与商城切换。ASAR 内 11 份关键程序/界面文件与当前源码逐字节一致；离线更新签名与安装包 SHA-256 已验证。源码审计通过 2038 份候选文件。所有操作使用隔离数据，未改动个人数据库、已保存云端凭证或圆盘固件。更新公钥延续现有发行版；公共 HTTPS 更新源及 Windows 发布者证书仍未配置。
