# EvoMyn 0.2.5 名称统一验收

日期：2026-10-22。范围为 Windows 桌面应用、PC MCP/看板、使用文档和发行配置。

## 变更

- 产品仅使用英文名 EvoMyn：窗口标题、导航、托盘、看板、接入配置、内置能力作者和 MCP 握手名称统一。
- Windows 程序为 `EvoMyn.exe`，安装包为 `EvoMyn-Setup-0.2.5-x64.exe`，快捷方式为 EvoMyn。
- 新导出客户端条目使用 `evomyn`；配置下载、源码启动脚本及公开源码包同步改名。
- 更新缓存文件及请求标识同步改名，版本递增为 0.2.5。
- 同目录旧程序的用户级开机启动项在正常安装启动时迁移；保留 Windows 中的禁用状态，不改其他安装或机器级启动项。隔离验收不操作正式启动项。

## 兼容与数据

沿用原安装 ID、LocalAppData 数据位置、更新签名公钥和内部 IPC/健康标识，保留数据库、配置、备份格式和上游来源说明。已有 `personal-memory` 客户端条目仍然可连接；替换时删除旧条目，避免重复接入。

本次未修改正式数据、云端配置或固件，未安装到当前用户的正式应用目录，也未发布在线更新。已有源码运行副本继续遵循首次创建后复用的规则，不自动覆盖本机配置或已安装代码。

## 验证

- 桌面 Node 测试 38 项通过，包含开机启动迁移、服务生命周期、安全限制和签名更新。
- 桌面 Python 后端与打包测试 22 项通过，包含真实 SDK、已有 stdio 会话开关、TLS 桥接与数据保留。
- 本地启动器/配置测试 32 项通过。
- 仓库工具测试 67 项完成：64 项通过、3 项平台/环境条件跳过。
- 运行时暂存审计通过，包含 43 个审阅后的应用文件；不带私有配置、数据库或模型。
- `npm run dist` 成功；Windows 文件资源 ProductName/FileDescription 为 EvoMyn，ProductVersion 为 0.2.5.0；ASAR 内名称、版本、页面标题和迁移模块核验通过。
- 打包后的 `EvoMyn.exe` 在独立用户目录运行验收通过：界面名称、MCP 握手名称、9 项工具、本地记录、宽窄窗口布局、MCP 总开关、可选小智引导、保存连接、重新连接、独立暂停和清理退出。
- TLS 验收仅连接本机临时服务，两次会话均成功调用 `archive_status`。没有连接正式小智接入点。

首次并发执行后端套件时，一项用例在初始化阶段遇到一次服务启动失败；该用例单独复跑及完整后端套件复跑均通过，未复现。未据此变更服务启动逻辑。
