# EvoMyn 0.2.9 界面范围调整 · 2026-10-22

按当前产品范围，个人记忆由用户按需手动备份；圆盘本地计划提醒在设备上使用，不进入桌面能力列表。

## 调整

- 记忆页移除 GitHub 云备份导航、面板及恢复密钥配置流程，不再挂载或请求该面板。旧 `#backup` 书签归一到记忆总览，默认导航为全部和五个默认分类。
- `PLANNER_OWNER=device` 时，共享能力目录不再返回计划提醒占位项，「我的能力」和商城同步移除。已有配置值保留，设备模式仍过滤和拒绝 PC 计划工具；历史显式 PC 模式兼容。
- MCP `archive_backup` 仍创建本地 SQLite 一致性快照，包含记忆、历史和分类，附件需另存。说明在 `server/personal-memory/BACKUP.md`，云端部分已明确标记为历史资料。
- 没有改写已安装数据库、现有备份、恢复私钥或私人接入配置；没有修改或烧录圆盘固件。
- 修正版本升级时误影响的三处依赖锁元数据，使其重新匹配已验证的实际依赖版本与完整性值；`npm install --package-lock-only --ignore-scripts --offline` 通过，没有变更安装依赖。
