获取 MCP 接入点

  1. 登录小智控制台

    使用设备绑定的账号登录。

  2. 找到对应智能体

    进入「智能体」，选择设备正在使用的角色，打开「配置角色」。

  3. 复制完整的连接地址

    在「MCP 设置」或「编辑功能」中找到「MCP 接入点」，复制完整的 wss:// 地址及其参数。
