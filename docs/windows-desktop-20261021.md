# Windows 桌面交付验收 · 2026-10-21

交付版本：0.2.0，Windows x64，每用户 NSIS 安装包。源码入口为 `desktop/`；原 MCP、看板业务仍维护在 `server/personal-memory/`，圆盘固件继续独立维护。本轮未烧录硬件、发布公网更新源或迁移个人数据库。

## 已实现

内置看板、能力包管理与接入页面；真实 MCP 执行总开关；独立小智云连接开关；托盘显示、关闭窗口继续运行及退出清理；客户端配置导出；开机启动设置；应用内签名更新检查、下载、重启安装及离线更新导入。

桌面壳与看板使用分离的渲染上下文，看板没有原生控制 preload。MCP 客户端通过标准 SDK 转发到应用拥有的执行进程，不能自行开启私有 worker。Windows 子进程挂起创建、加入 Job 后恢复；退出释放子进程树。客户端登记进程身份，更新等待真实退出；身份不符的陈旧 PID 不会阻塞更新。

默认数据目录是 `%LOCALAPPDATA%\PersonalMemory\service\`，安装与用户数据分开。代码刷新使用固定文件清单，保留数据库、模型、凭证、功能包开关与偏好。默认不导入其他源码安装的数据。

## 发布边界

应用内更新使用固定 Ed25519 公钥校验签名说明，再校验安装文件。签名离线升级已实际验证；尚未发布公共 HTTPS 更新源，默认界面明确显示未配置。配置真实更新源后才能验收公网版本发现和下载流程。当前 EXE 没有 Windows Authenticode 发布者证书；Ed25519 更新签名不能替代该证书。
