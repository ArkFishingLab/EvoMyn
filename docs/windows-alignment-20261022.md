# Windows 0.2.4 顶部对齐修正 · 2026-10-22

能力、记忆和客户端接入使用一致的内容左边距与顶部起点。取消能力工作区的纵向自动居中；能力标题、说明、页签和列表从顶部顺序排列。内嵌页按主窗口宽度取得边距，避免其自身较窄的视口误触发另一档响应式边距。保留原生内容区与看板的滚动槽宽度，标题不随滚动条出现而横向跳动。

回归先记录三页标题实际坐标并复现差异，再修正布局。在普通和最小窗口下，记忆与能力标题全局坐标一致，与客户端接入的横纵误差均小于 1 个 CSS 像素。既有四页、分类/搜索、备份、商城、真实 MCP 和可选小智连接使用隔离配置复测。截图对暂不可捕获的 Chromium 表面采用有界重试，等待页签视觉过渡完成后取图。

Node 35 项通过，补充了最小化窗口返回零尺寸时保留有效布局的回归检查。隔离验收初始页面在后台捕获，避免被最小化操作干扰。Windows x64 0.2.4 安装包已构建，打包后的应用通过同一套隔离页面/标题坐标、MCP SDK 与 TLS 连接验收。源码审计通过 2039 份候选文件。用户数据库、云端凭证和固件未改动。更新公钥延续原发行版，公共 HTTPS 更新源与 Windows 发布者证书仍未配置。
