# Windows 0.2.2 布局整理验收 · 2026-10-22

应用采用一套主导航：记忆、能力、客户端接入、应用设置。MCP 总开关常驻顶栏；小智开关与连接引导只属于客户端接入。

- 记忆：保留搜索、五类档案、详情与备份，移除重复的品牌与跨页面导航。
- 能力：保留我的能力、能力商城、功能包开关及调用记录；云端连接指标移出主要视觉区域，连接配置统一进入客户端接入。
- 客户端接入：Codex TOML、Claude / 其他 stdio 客户端 JSON 并列导出；小智配置默认折叠，缺少接入点时自动展开、滚动并聚焦输入框。小智保持可选，不影响本机 MCP。
- 应用设置：仅保留桌面偏好、本地数据与更新；删除重复的服务开关和客户端导出。

统一字号、灰阶、内容宽度和间距。内嵌看板只应用样式，不获得 preload 或原生 IPC。商城官方目录及来源链接经主进程校验后在系统浏览器打开，仅允许指定 HTTPS 域名。

同时修复两项回归：迟到的看板导航不能覆盖已选择的设置或接入页；运行时复制清单补齐看板状态接口依赖的 SOURCE.json 和许可证，避免读取状态返回 404。

- 延迟导航回归先复现失败，再验证修复。缺少接入点时输入框在视口内且获得焦点；保存、重试、独立云暂停及退出清理继续通过。
