## 当前分工与操作

圆盘保存和执行提醒。小智通过设备侧 `self.planner.get_context/list/create/update/complete/cancel`
操作提醒；PC 不再提供实时计划工具或调度。PC 关闭时，圆盘仍执行已有提醒；
PC 离线但圆盘仍连接小智云时，可继续通过设备工具设置提醒。
完全断网时，已保存且时钟有效的提醒继续运行，云端语音无法接收新指令。

只有用户明确完成才生成日志；响铃、停止铃声、取消均不生成完成记录。
圆盘将日志持久保存在待归档队列，同一局域网的 PC 恢复后经 HTTPS 补传。
PC 使用稳定事件 ID 和原始归档历史去重，先落盘再回执；圆盘收到匹配回执并保存后才出队。
测试日志写入隔离库，原个人记忆库未加入测试记录。

看板为 `http://127.0.0.1:18768/memory/`，能力管理为 `/memory/mcp/`。
PC 保留档案和商城，当前云端连接 11 个工具：档案 9 个、世界时间 2 个。
旧计划页面返回 HTTP 410，旧 HTTP 18769 / WebSocket 18771 均已关闭。
服务器 `203.0.113.10` 的 `/planner/ws` 已改为 HTTP 410，反向 SSH 隧道不再运行，
项目 memory 服务保持停止；没有停止整台服务器或其他应用。

系统更新入口：**圆盘设置 → 系统更新 → 检查更新 → 确认下载 → 重启**。
当前更新与日志网关为 PC 的 `https://192.0.2.10:18773`，需要 PC 后台看板进程运行且两端局域网可达，
无需公网 IP。HTTPS 使用固定 CA 和设备凭证，不使用跳过证书验证。
当前地址固定；建议路由器保留该 PC 地址。更换网段或地址时需同步服务地址和证书配置。
PC 不在线只影响归档与检查/下载更新，不影响圆盘已保存提醒。

闲置约 60 秒关闭面板，不再因闲置 5 分钟关机。
保留原电源键短按亮灭屏、AXP2101 长按手动关机及低电量保护配置。
提醒到点可亮屏响铃；自动熄屏及提醒切页会锁存触摸状态，须先松手再进行下一次操作。

## 后续发布

正常功能和界面修改可以继续 OTA。保留设备私有服务配置、固定 CA、板型标记及现有分区。
在 `xiaozhi-firmware/CMakeLists.txt` 增加数字 `x.y.z` 版本号，然后在项目目录执行：

```powershell
./tools/build_round.ps1
& ./artifacts/local-memory-mcp/.venv/Scripts/python.exe -X utf8 `
  server/personal-memory/vendor/device_updates.py `
  --build-bin D:/round-build/build/xiaozhi.bin `
  --output-dir artifacts/local-memory-mcp/device-releases `
  --version <与本次编译一致的新版本> --notes "本次更新说明"
```

发布器验证实际 ESP 镜像、项目、板型/分区标记、校验和、版本和大小，先原子写镜像再切换清单。
设备只下载清单对应的固定哈希路径，校验后写入非当前 OTA 分区；下载完成不立即改变启动分区，
明确选择重启后再切换。新启动等待本地提醒恢复与显示初始化健康后确认，否则保留启动回退。
小智官方激活/语音接入继续工作，圆盘拒绝通用固件更新入口，避免覆盖定制版本。
涉及 bootloader、分区布局或凭证轮换时需要单独评估，不能直接当作普通应用更新。

## 尚未实测的边界

- 上述设备 MCP 验收通过物理 USB 调用真实处理器；未人工对小智说创建/完成提醒，也未做实际声音唤醒的端到端验收。
- 实际物理电源键长按、低电量放电关机、真正断电故障测试尚未执行；已验证的是软件重启和启动回退。
- 纯电池电流、温升和续航尚未测量，不能据此宣称续航改善。
- 软重启后时钟恢复已验证；完全断电且时钟失效时，需要联网校时后才能准确执行绝对时间提醒。
- 待归档队列上限 16 条；满队列时拒绝新的完成操作并提示，避免丢失未归档事实。提醒上限 32 条。
- 当前 PC 后台进程已启动，但未新建 Windows 开机任务；PC 重启后需重新启动本地看板/桥接进程。
