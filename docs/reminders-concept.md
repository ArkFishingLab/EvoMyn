# 圆盘备忘与日程：产品及实现构思

> 历史证据：本文记录当时的部署与验收，不是当前安装要求；地址、设备身份和个人路径已替换为示例。当前入口见项目 README 与 docs/architecture.md。

状态：首版已部署并烧录。已实测设备同步、熄屏亮屏响铃、停铃、断网提醒，以及离线“稍后十分钟”重连同步；临时测试事项已清理。完整语音创建链路、通话中提醒、电池续航及断电恢复仍需实际使用验证。
以下保留产品构思，交付细节及边界以 `server/personal-memory/PLANNER.md`、板型 README 为准。

## 定位与数据归属

放在同一个“个人信息库”产品里，新增“待办与日程”入口，但采用独立的结构化事项/提醒表，以 ID 关联已有的人物、事件和资料。现有五类档案保持原有含义，不能把未来计划当成已经发生的事件。

三类内容共享语音入口：
- 备忘：仅正文，没有必须执行的时间；可随时转为待办。
- 待办：待处理的事，时间可空；截止时间不自动等同于闹钟。
- 日程：发生时间明确，可设提前提醒；未知结束时间不随意补成一小时。

示例数据仅为界面演示，不写入真实个人库。完成后保留状态及完成时间供检索，不自动复制一份到日志。响铃、停止铃声与完成任务是三个不同状态。

## 圆盘界面

沿用深炭黑、暖金、雅黑 UI 字体、466×466 圆屏安全区，不做密集月历。

1. 首页保留时间、主语音键、设置；增加“下一提醒”一行和“待办日程”入口。
2. 清单一次显示两件事，按时间排序，可滚动；分近期、无日期。已完成记录进入历史视图。长标题在详情完整展示。
3. 语音创建后显示结果：事项、绝对日期、时间、响铃开关、同步状态。明确指令直接执行；只有时间歧义或识别不清才追问。
4. 到点亮屏、播放本地铃声，显示事项；提供“已完成”“稍后10分钟”“只停止铃声”。提醒音量独立于对话音量，可选静音仅亮屏。
5. 网页个人库新增待办与日程页：列表/日历、搜索、创建编辑、关联档案、历史；现有只读接口保持只读，新的写操作另设鉴权与 CSRF 防护。

## 语音交互

- “记一下，整理项目资料”：创建无日期待办，不擅自设闹钟。
- “明天上午九点半提醒我给客户回电话”：创建并提醒，回读具体日期及时间。
- “明天下午三点开项目会，提前十分钟提醒”：日程与提醒分别保存。
- “刚才那个改成十点”“这件事做完了”“每天晚上九点提醒”：通过事项 ID 更新，保留修改历史。
- “下周找时间处理”保留模糊时间，不擅自定到某天某个整点；用户要求定时响铃时再澄清。

只有数据库提交成功才说“已记录”；只有设备已确认缓存到对应版本才说“圆盘会提醒”。设备离线时明确显示/播报“已记录，圆盘待同步”。重试同一句请求不会重复创建。

## 实现分工

**服务端**
- 增加 PlannerStore，使用独立 tasks、reminder_occurrences、task_history、device_deliveries 表及迁移，和现有档案共享身份、关联、备份与搜索入口。
- 字段包括种类、标题、正文、状态、开始/结束/截止时间、时区、重复规则、提醒时间、关联 ID、版本与修改时间。
- MCP 提供 create/list/update/complete/snooze/cancel 等工具。LLM 解释意图，确定性代码检查日期、时区及重复规则；数据库提交不等待语义向量生成。
- 服务端保存 UTC 与 IANA 时区（默认 Asia/Shanghai）。相对时间以请求发生时的实际时间解析，不能依赖模型猜“今天”。
- 增加设备专用同步通道，建议设备主动建立鉴权 WSS 接收版本变化并回执；断线后按版本补齐。设备令牌可撤销且仅限本设备，不使用网页管理员密码。
- MCP 工具调用与设备提醒投递分开实现；不假定小智云的自定义 MCP 能主动替我们让设备响铃。

**设备端**
- 缓存未来一段时间的提醒及其版本，采用有上限的队列与原子持久化；本地按绝对时间触发，不等到点才询问 AI。
- 在线同步、解析与持久化在独立低优先级工作任务执行，主事件循环只处理小消息，音频线程不做网络或数据库操作。
- 使用固件自带短铃声，断网仍可响；朗读事项可作为联网增强，不能成为响铃的依赖。
- 唯一提醒实例 ID + 本地触发记录 + 服务端回执去重；已完成/取消的旧版本不能因重连复活。离线的稍后/完成操作进入持久化发件队列。
- 单调计时用于短间隔等待，UTC 时钟用于实际日期；校时后重新计算下一提醒，避免时钟跳变重复响。
- 断电后重新启动若未校时，不把无效时钟当成准确时间。错过的旧提醒以摘要呈现，不把多个历史闹钟逐个补响。
- 提醒和对话统一做音频仲裁，避免叠音；首版可中止当前播报后切到提醒，后续继续对话，不承诺恢复被中止的语音片段。

## 必须调整的电源策略

当前固件电池模式存在闲置自动关机。有未来提醒时应改为低功耗待机并保持本地计时，熄屏可以提醒。真正断电/长按关机不能承诺到点自动开机响铃；未验证 AXP/RTC 能力前不以此作为交付功能。提醒唤醒需明确恢复屏幕/亮度，不能误用“切换亮灭”导致已经亮着的屏幕被关掉。

## 分期建议及验收

首版：语音创建/查询/修改/完成、无时间备忘、单次及每天/每周重复、圆屏清单、独立提醒音量、到点亮屏响铃、稍后10分钟、网页管理、离线缓存及去重。

验收范围：断网到点、重启及补同步、改时间/取消后旧提醒不响、重复 MCP 请求、已响不等于已完成、每日实例互不串状态、时钟前后跳、同时多条提醒、对话时到点、低电与熄屏、离线完成后重连不复活。自动化测试与本次实机测试的区分见实现计划；临时测试记录已清理，原个人档案保留。提醒由服务端同步和固件本地计时实现。
